# Maze Simulation GUI - User Guide

## Overview
The Mission Control GUI (`MissionGUI.py`) provides a graphical interface to run maze exploration simulations using the `discover11.py` module.

## Prerequisites
Before running the GUI, ensure you have the required Python package installed:

```bash
pip install matplotlib
```

## Features
- **Maze Size Configuration**: Set the maze size (NxN, where N is between 2 and 20)
- **Adjustable Visualization Speed**: Control the animation speed with configurable delay
- **Live Plot Visualization**: Real-time maze exploration display on the right side of the GUI
- **Start Simulation**: Launch the maze exploration with a single button click
- **Real-time Output**: See simulation progress in the output console (left side)
- **Save Data**: Exports results to `maze_data.json`

## How to Use

### 1. Launch the GUI
```bash
cd C:\Workspace\HuluDrone\MoW-Maze\challenge1
python MissionGUI.py
```

### 2. Configure Parameters
- **Maze Size (NxN)**: Enter the desired maze size (e.g., 5 for a 5x5 maze)
- **Visualization Delay (ms)**: Set the delay between animation frames (default: 50ms)
  - Lower values = faster animation (e.g., 10ms for quick runs)
  - Higher values = slower animation (e.g., 200ms to see each step clearly)
  - Set to 0 for instant completion
- **Start & Target**: These are automatically generated by the maze algorithm

### 3. Run Simulation
1. Click the **"▶ Start Simulation"** button
2. Watch the **live plot on the right** showing the robot exploring in real-time
3. Monitor the **output console on the left** for progress updates
4. Wait for the simulation to complete

### 4. View Results
After simulation completes:
- **Left Panel (Output Console)**: Shows exploration statistics and completion status
- **Right Panel (Live Visualization)**: Displays the final maze state with shortest path
- **Layout
The GUI uses a two-column layout:
- **Left Column**: Input parameters, controls, and text output console
- **Right Column**: Live matplotlib visualization showing maze exploration in real-time

### Input Parameters
- **Maze Size**: Controls the dimensions of the generated maze (default: 5x5)
- **Visualization Delay**: Animation speed in milliseconds (default: 50ms, lower = faster

## How It Works

1. **Maze Generation**: Creates a random maze with specified dimensions
2. **Robot Exploration**: Robot uses DFS to explore all cells, sensing walls
3. **Path Finding**: Calculates shortest path from start to target
4. **Visualization**: Animates the exploration process
5. **Data Export**: Saves maze structure and exploration data to JSON

## Output Files

### maze_data.json
Contains:
- Maze structure (walls configuration)
- Start and target positions
- Shortest path with coordinates and directions
- All sensed barriers during exploration

## Visualization Legend
- **Green cell**: Start position (S)
- **Red cell**: Target position (T)
- **Orange circle**: Robot position (R)
- **Light blue dots**: Visited cells (exploration trail)
- **Green dots**: Shortest path cells
- **Yellow walls**: Currently sensing
- **Blue walls**: Previously sensed
- **Black walls**: Actual maze walls

## Notes
- **Live visualization** updates in real-time as the robot explores (embedded in the GUI)
- The visualization delay controls animation speed - adjust for your preference
- Emergency Stop may not immediately halt the simulation due to threading constraints
- For larger mazes (>10x10), exploration may take longer
- Shortest path navigation runs at 2x the configured delay for better visibility due to threading constraints
- For larger mazes (>10x10), exploration may take longer

## Troubleshooting

### "ModuleNotFoundError: No module named 'matplotlib'"
Install matplotlib: `pip install matplotlib`

### Simulation doesn't start
- Check that maze size is between 2 and 20
- Ensure discover1not updating
- Check if matplotlib is properly installed
- Look for error messages in the output console
- Ensure visualization delay is not set too low (try 50ms)
- Try closing and restarting the GUI

### Animation too fast/slow
- Adjust the "Visualization Delay" parameter before starting
- Lower values (10-30ms) for faster animation
- Higher values (100-500ms) for slower, step-by-step viewingear
- Check if matplotlib is properly installed
- Look for error messages in the output console
- Try closing and restarting the GUI
